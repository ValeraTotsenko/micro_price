# micro_price

Исследовательский проект на Nautilus Trader. Проверяем, предсказывает ли асимметрия глубины стакана BTC/USDT движение цены и остаётся ли доход после моделирования исполнения. Репозиторий пока содержит проектную документацию.

| Документ | Что в нём искать |
|---|---|
| [Исходная идея](vamp-strategy-spec.md) | Мотивация VAMP, адаптация глубины и межбиржевой сигнал |
| [План разработки](docs/development-plan.md) | Очерёдность работ, результаты этапов и условия перехода |
| [Данные и индикаторы](docs/data-and-signals.md) | Восстановление стакана, единицы, формулы и контрольные примеры |
| [Протокол эксперимента](docs/experiment.md) | Параметры первого прогона, исполнение, метрики и критерии оценки |

Для первой реализации используем план и протокол из каталога `docs`. Бэктест одной площадки предшествует ML и подключению второй биржи.
